# Milestone 6 — Admin `/settings` UI (parity)

Status: complete. Source oracle: `src/modules/settings/commands/settings.ts`
(549 lines) over `docs/oracle-snapshot/settings-service.ts`. The DB
`SettingsStore` (write-through cache + Postgres upsert) shipped in M5b; M6
adds the missing `toggle_auto_dump` and the entire command/callback surface.

## Deliverables

- `crates/bot/src/handlers/settings.rs` — the full panel:
  - `buildSettingsKeyboard` parity: mode row, album/playlist/artist row,
    .TXT/multi-link row, auto-dump + storefronts row, limit presets
    (25/50/100/Unlimited, ✅ marks the active), Refresh/Close.
  - `buildStorefrontsKeyboard` parity: 4-per-row country toggles (us gb jp
    in ca au de fr), Back/Close.
  - `renderSettingsText` / `renderStorefrontsText` — exact oracle strings
    (mode descriptions incl. emoji, 🟢 Enabled/🔴 Disabled, "Enabled
    (Daily)", uppercase storefront list, Unlimited/`N tracks` limit).
  - `/settings` subcommands: `mode <live|cache_only|paused>`,
    `album|playlist|artist|txt|batch_txt|multilink|multi_link|autodump|
    auto_dump <on|true|1|off…>`, `storefronts|storefront|sf
    <add|rm|remove|del|set> <code…>` (comma-splitting parity), `limit <n>`
    (0 = unlimited) — each answers with the exact oracle confirmation or
    usage string.
  - `settings:*` callbacks: close (channel-aware delete), refresh,
    sf_menu, mode cycle (Live→CacheOnly→Paused→Live with answer toast),
    per-flag toggles, `settings:limit:<n>`, `settings:sf:toggle:<sf>`
    (add/remove flip on the storefronts menu). Admin re-checked on every
    callback with the oracle's `Unauthorized. Owner only.` alert.
  - NOT_MODIFIED-style edit errors swallowed like the oracle.
- `crates/db/src/settings.rs` — `toggle_auto_dump` (oracle
  `toggleAutoDump`) added to the existing toggle family.
- `crates/bot/src/rip_deps.rs` — public `settings()` /
  `settings_snapshot()` accessors (panel reads go through the shared
  in-memory snapshot; writes write-through).
- Callback routing: `settings:` prefix dispatch in `handlers::register`.
- `crates/bot/tests/settings.rs` — exact-string parity tests for both
  render texts (all three mode descriptions, limit variants), the
  storefront list, and the POPULAR_STOREFRONTS order.

## Semantics identical to the oracle

- Admin-only on both the command and every callback (owner id from env).
- Mode cycling order and the toast labels (`Mode: Live Ripping` etc.).
- Storefront membership is case-insensitive; removal falls back to
  `['us']` when the list would empty; `set` dedupes and lowercases.
- `maxCollectionTracks`: negative input clamps to 0 (Unlimited); presets
  highlight via ✅.
