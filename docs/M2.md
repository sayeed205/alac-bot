## parser.rs — port of parser.ts exactly

Use the `regex` crate. Regexes translated verbatim (case-insensitive via `(?i)`, `matches!`-style `find` for unanchored, `^...$` anchors preserved):

1. `PLAYLIST_RE`: `(?i)music\.apple\.com/(?:([a-z]{2})/)?playlist/(?:[^/]+/)?(pl\.(?:u-[a-zA-Z0-9]+|[a-zA-Z0-9]+))` — capture groups: 1 = storefront (lowercased), 2 = playlist id
2. `BARE_PLAYLIST_ID_RE`: `(?i)^(pl\.(?:u-[a-zA-Z0-9]+|[a-zA-Z0-9]+))$`
3. `ARTIST_RE`: `(?i)(?:music|itunes)\.apple\.com/(?:([a-z]{2})/)?artist/(?:[^/]+/)?(\d+)`
4. `BARE_ARTIST_ID_RE`: `(?i)^artist[:/](\d+)$` (TS has the /i flag — case-insensitive)
5. `SONG_WITH_ALBUM_RE`: `(?i)music\.apple\.com/(?:([a-z]{2})/)?album/(?:[^/]+/)?\d+\?i=(\d+)`
6. `SONG_DIRECT_RE`: `(?i)music\.apple\.com/(?:([a-z]{2})/)?song/(?:[^/]+/)?(\d+)`
7. `ALBUM_RE`: `(?i)music\.apple\.com/(?:([a-z]{2})/)?album/(?:[^/]+/)?(\d+)`
8. `BARE_ID_RE`: `^\d+$`

**Order matters**: playlist url → bare playlist → artist url → bare artist → song-with-album (?i=) → song direct → album → bare id (track). Storefront group lowercased when present. TS uses `.match()` = first match anywhere; use `Regex::captures` (finds first). Use `once_cell::sync::Lazy` (or std OnceLock) for compiled regexes.

Functions (public interface):
- `pub fn parse_single_item(raw_token: &str) -> Option<ParsedTargetItem>` — trim, empty→None, order above.
- `pub fn extract_batch_items(content: &str) -> Vec<ParsedTargetItem>` — split lines on `[\r\n]+`, tokens per line split on whitespace; for each token: if starts with `#` or `//` BREAK (stop remaining tokens on that line); parse, dedup by `{kind}:{id}` preserving first-seen order.
- `pub fn parse_alac_input(raw_text: &str, reply_text: Option<&str>) -> Option<ParsedAlacInput>` — trim, split whitespace; if first token starts with `/` drop it; `-f`/`--force` anywhere → force=true (other tokens kept); parse remaining tokens in order with dedup; if none parsed AND reply_text given, parse reply tokens (same dedup); if still empty → None; flags from first item (is_album/is_playlist/is_artist), track_id = first id, storefront = first item's storefront. NOTE: `-f` handling happens on the command's tokens only (TS shifts the command token then filters; reply tokens are parsed as items but never contain -f — actually TS parseAlacInput does NOT filter -f in reply tokens, it just parseSingleItem's them; `-f` would fail parseSingleItem → skipped. Match that.)

Port every test from parser.test.ts into `#[cfg(test)] mod tests` in parser.rs (all 15 cases incl. batch items). Use assert_eq/Option checks mapping toEqual semantics.

## catalog — port of catalog.service.ts

### Transport seam (catalog/transport.rs)

```rust
#[derive(Debug, thiserror::Error)] pub enum TransportError { /* timeout, http status(u16), network */ }

pub trait Transport: Send + Sync {
    fn get(&self, url: &str, timeout: std::time::Duration)
        -> impl std::future::Future<Output = Result<String, TransportError>> + Send;
}
```
(RPITIT — stable; static dispatch, no dyn needed.)

- `ReqwestTransport` (behind nothing; constructed with `reqwest::Client`): sets `User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/145.0.0.0` on every request, per-request `timeout`, `.text()` body. `reqwest = { version = "0.12", default-features = false, features = ["rustls-tls"] }` in engine/Cargo.toml (verify it builds; adjust version/features if cargo disagrees).
- Tests provide a `FakeTransport` serving canned JSON per-URL, recording served URLs in a `Mutex<Vec<String>>` (for cache-hit and fallback-order assertions).

### Cache (catalog/cache.rs)

TS semantics (CatalogService private Map cache): capacity 500, TTL 10min (constructor-parameterizable). get: expired→remove+None; hit→refresh recency (delete+reinsert). set: if at capacity evict least-recent (front); store value+expiry. Implement with `indexmap::IndexMap<String, (std::time::Instant, T)>` + `std::sync::Mutex` (short critical sections, no await inside). `pub(crate)` only — internal to Catalog, not part of the interface.

### Catalog (catalog/mod.rs)

```rust
pub struct Catalog<T: Transport> { transport: T, cache: Mutex<Cache>, /* cap, ttl from constructor */ }
pub type SharedCatalog = Catalog<ReqwestTransport>; // convenience alias
impl<T: Transport> Catalog<T> {
    pub fn new(transport: T) -> Self;                       // cap 500, ttl 10min
    pub fn with_limits(transport: T, cap: usize, ttl: Duration) -> Self;
    pub async fn fetch_track_meta(&self, track_id: &str, storefront: &str) -> Result<TrackMeta, CatalogError>;      // storefront default "us" handled by caller passing it
    pub async fn fetch_album_tracks(&self, collection_id: &str, storefront: &str) -> Result<AlbumTracks, CatalogError>;
    pub async fn fetch_artist_tracks(&self, artist_id: &str, storefront: &str) -> Result<ArtistTracks, CatalogError>;
    pub async fn search_catalog(&self, term: &str, limit: i64, storefront: &str) -> Result<Vec<TrackMeta>, CatalogError>; // NEVER errors — returns empty vec on failure (TS parity)
    pub async fn fetch_charts_albums(&self, storefront: &str, limit: i64) -> Result<Vec<ChartAlbum>, CatalogError>;
    pub fn clear_cache(&self);
}
```
Storefront handling: `sf = (storefront || 'us').to_lowercase()` equivalent: empty→"us", lowercase.

`REGIONAL_STOREFRONTS = ["jp","gb","in","ca","de","fr","au"]`.

**Lookup endpoints** (exact):
- track: `https://itunes.apple.com/lookup?id={urlencoded id}&country={sf}` — timeout 15s
- album: `...&entity=song&country={sf}` — timeout 25s
- artist discography: `...&entity=album&limit=200&country={sf}` — timeout 30s
- artist collection batches: `?id={csv of collection ids}&entity=song&country={sf}` — timeout 20s, chunks of 25
- artist song fallback: `?id={artistId}&entity=song&limit=200&country={sf}` — timeout 20s
- search: `https://itunes.apple.com/search?term={enc}&entity=song&limit={limit}&country={sf}` — timeout 15s
- charts: `https://rss.marketingtools.apple.com/api/v2/{sf}/music/most-played/{limit}/albums.json` — UA `Mozilla/5.0` (differs!), timeout 15s

**Fetch flow parity (track/album/artist share the pattern):**
1. cache key `track:{sf}:{id}` / `album:{sf}:{id}` / `artist:{sf}:{id}` — hit→return
2. do_fetch on sf; on success cache under key + return
3. on error: if sf != "us": try "us", success→cache+return; on to regional chain: REGIONAL minus sf, try each, first success→cache+return
4. rethrow ORIGINAL error

**do_fetch_track_meta**: parse JSON `{results: [...]}`; find first item where `wrapperType=="track" || kind=="song" || String(trackId)==track_id`; if none → error "iTunes found no song matching track ID {id}"; map via mapping; override `meta.id = trackItem.trackId or original id`. HTTP !ok → error `iTunes lookup failed (HTTP {status})`. Timeout/network → TransportError mapped into CatalogError with elapsed info.

**do_fetch_album_tracks**: results: collection = find `wrapperType=="collection"`; tracks = filter `wrapperType=="track" || kind=="song"`; no tracks → error `iTunes found no tracks for collection {id}`; album meta: from collection (id=collectionId or original, title/album=collectionName, artist/album_artist=artistName, duration 0, explicit from collectionExplicitness, release_date slice(0,10), artwork formatted) else first track.

**do_fetch_artist_tracks**: artistItem = find `wrapperType=="artist"` → artistName; collectionItems = filter collection; if any: chunk collectionIds (numbers only) by 25, batch lookup each chunk (on batch error: debug log + continue); collect tracks (wrapperType track || kind song), dedup by String(trackId) preserving order; if still 0 tracks: fallback `entity=song&limit=200` lookup, same filter+dedup, artistName fallback from its artist wrapper if still empty; if still 0 → error `iTunes found no tracks for artist {id}`; artistName final fallback: first track's artist, then "Unknown Artist". NOTE: successful result requires ≥1 track.

**search_catalog**: do_search on sf; returns [] on timeout/http error (log, no error); filter+map tracks; if empty && sf != "us": do_search "us"; if still empty: regional chain minus sf, stop at first non-empty; cache FINAL result (possibly empty) under `search:{sf}:{limit}:{term.trim().to_lowercase()}`; never errors.

**fetch_charts_albums**: cache key `charts:{sf}:{limit}`; fetch, !ok → error `Failed to fetch Apple Music charts (HTTP {status})`; map feed.results[]: id, name→title, artistName→artist, url, artworkUrl100→formatArtwork (Option→None when absent, Some when present — NOTE: charts mapping keeps Option, only track mapping coerces to ''), releaseDate Option, genre = genres[0].name Option; cache under DEFAULT ttl.

**Mapping quirks (mapping.rs)**: `format_artwork_url`: None/absent→"" for itunes items; present→replace FIRST `\d+x\d+bb` occurrence with `3000x3000bb` (regex). `map_itunes_item`: as TS (release_date = first 10 chars; duration = millis/1000 rounded; explicit = trackExplicitness=="explicit"; id = String(trackId or "")).

serde structs for raw iTunes JSON: all fields Option, `#[serde(default)]`, rename to camelCase field names (trackId, collectionId, artistId, trackName, collectionName, artistName, primaryGenreName, releaseDate, trackNumber, trackCount, discNumber, discCount, trackTimeMillis, trackExplicitness, collectionExplicitness, artworkUrl100, wrapperType, kind). Numbers arrive as JSON numbers — use serde_json::Value-agnostic `Option<f64>`/i64? iTunes sends integers; use Option<i64> for ids/counts and Option<f64> for trackTimeMillis (it's an int; f64 handles ints fine up to 2^53). Charts feed: separate structs (feed.results[].id/name/artistName/url/artworkUrl100/releaseDate/genres[].name).

`CatalogError` (thiserror): `Timeout { elapsed_ms, context }`, `Http { status, context }`, `Network { context, source }`, `NotFound(String)` (the "no song/collection/artist" messages), `BadJson { context, source }`. Context = which operation. These messages later surface to users via rip failures — keep them close to TS text.

tracing spans: `info_span!("itunes_track", track_id, storefront)` etc. matching TS span names; debug! for querying/fallback retries; error! on failures; info! on resolved (with artist/title/track_count/elapsed_ms fields).
