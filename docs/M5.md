- `startJob(options, depsOverride?)` (80-842) — THE core; returns `RipJobSummary | null`; throws if deps missing ('RipOrchestrator dependencies not configured. Call setDependencies() first.')

startJob flow (verbatim semantics):
1. Destructure: chatId, userId, userName, deliveryChatId, isGroup, isForce, isCacheOnly, singleStorefront, parsedItems, statusMsgId, replyToMessageId, isAdmin.
2. Destructure deps: tg, service, ripper, queue, settings (custom, default `settingsService`), `uploadRetryBaseMs = 3000`.
3. Maintenance gate: `if (!settings.canRipLive(isAdmin) && !isCacheOnly) throw 'Live ripping is temporarily paused for maintenance. Only cached tracks can be played right now.'`
4. jobController = new AbortController; `jobId = 'job_' + Date.now() + '_' + Math.random().toString(36).slice(2,6)`.
5. jobHeader initial: single track → `Track ${id}`; album → `Album ${id}`; playlist → `Playlist ${id}`; artist → `Artist ${id}`; multi → `Batch (${n} links)`.
6. Register job; emit `job:created`.
7. emitProgress(activityOverride?, activeDownloadText?, activeUploadText?) closure — completedTracks = cached+ripped+failed; percent = round(completed/total*100) (0 if total 0); emits `job:progress`.
8. `emitProgress('Resolving metadata & tracklist...')` then resolve each parsedItem:
   - abort check per item: throw `'Download was cancelled'`
   - effectiveSf = `item.storefront || singleStorefront || 'us'`
   - track → push `{id, storefront: effectiveSf}` (NO title/artist)
   - album → `catalogService.fetchAlbumTracks(id, sf)` → albumName/albumArtist captured; push each `{id, title, artist, storefront}`
   - artist → `catalogService.fetchArtistTracks(id, sf)` → albumArtist = artistName; push each `{id, title, artist, storefront}`
   - playlist → `fetchPlaylistTracks(id, sf)` (NOT catalogService) → push each `{id, title, artist, storefront}`
   - per-item try/catch: on error log 'Failed to resolve target item' and throw `` `${item.type} ${item.id}: ${errMsg}` ``
9. Empty check: `'No valid tracks found to process.'`
10. Dedup by id preserving order (seenTrackIds set).
11. Cap: `maxCollectionLimit = settings.getMaxCollectionTracks()`; only if `!isAdmin && maxCollectionLimit > 0 && len > limit`: cappedCount = len - limit; `tracksToProcess = slice(0, limit)`; warn 'Collection capped for non-admin user'.
12. Job header refinement: if albumName && albumArtist → `${albumArtist} - ${albumName}`; else single with title&&artist → `${first.artist} - ${first.title}`; single without → `Track ${first.id}`; else `Batch (${n} tracks)`.
13. Cache lookup: `existingTracksMap = await service.findCachedTracks(requestedIds)`.
14. Force+admin purge: for each cached → deleteTrack, collect messageIds, `tg.deleteMessagesById(env.DUMP_CHANNEL_ID, oldMessageIds)` (errors swallowed).
15. Pre-queue cache handling loop:
   - abort check: throw 'Download was cancelled'
   - cached && isCacheOnly → cachedCount++, info 'Track already cached in dump channel', emitProgress('Recognized cached tracks...')
   - cached && !isCacheOnly → sendDumpCopy {toChatId: deliveryChatId, messageId: cached.messageId, replyTo: deliveryChatId === chatId ? replyToMessageId : undefined, silent: isMultiTrack}; logRequest {telegramId: userId, chatId, appleTrackId, isCacheHit: true, durationMs: 0, status: 'completed'}; cachedCount++; emitProgress('Delivered cached tracks...'). On copy failure → error 'Failed to deliver cached track copy, marking for re-rip', push to uncachedItems.
   - !cached → uncachedItems.push
16. All-cached completion: completed=true; summary {cachedCount, rippedCount: 0, failedCount: 0, failedTracks: [], skippedUncachedTracks: [], totalElapsedSec: '0.0', cappedCount, maxCollectionLimit, isCacheOnly, isGroup}; emit job:completed; return.
17. cache_only mode + uncached items (non-admin live-blocked): same summary but skippedUncachedTracks = uncached ids; return.
18. Live path: `emitProgress('Queued for ripping...')`; failedTracks[]; `info('Rip job queued', {...})`; queueStartTime; `summary = await queue.enqueue(async (signal) => {...})`:
    a. debug 'Rip job started from queue'; emit job:started.
    b. ripJobDir = `join(os.tmpdir(), 'rip_job_' + Date.now() + '_' + rand36)`; mkdir recursive (swallow errors).
    c. downloadChannel = `BoundedChannel<PipelineItem>(1)`; uploadChannel = `BoundedChannel<PipelineRipResult>(2)`.
    d. Producer: for item in uncachedItems — abort/cancel break; push {trackId, job, storefront, meta {title, artist}}; finally downloadChannel.close().
    e. Downloader (worker 1): for-await over downloadChannel — abort/cancel break; trackLabel = meta.title && meta.artist ? `${artist} - ${title}` : `Track ${trackId}`; onProgress(status, downloaded?, total?) → with bytes: `activeDownloadText = '⬇️ <b>{trackLabel}:</b> <code>{formatByteProgress(downloaded, total)}</code>'` else `'⬇️ <b>{trackLabel}:</b> {status}'` (escaped); sets currentJob.activeActionText; emitProgress(undefined, activeDownloadText, activeUploadText). rip via `ripper.rip(trackId, onProgress, storefront, jobController.signal, ripJobDir)`. Success → clear texts, push to uploadChannel {trackId, job, ripResult, startTime}. Failure → clear texts; if cancelled/aborted break; failedTracks.push; failedCount update; error 'Rip job failed'; logRequest status 'failed' errorReason; emitProgress('Processing next track...'); **circuit breaker**: errMsg contains 'timed out'/'mirror'/'502'/'503' (lowercase) → failedTracks.push {id: 'Remaining tracks', error: 'Mirror service offline / unreachable (stopped remaining batch)'}; error 'Lossless mirror appears to be down, aborting remaining batch to prevent repeated timeouts'; break. finally uploadChannel.close().
    f. Uploader (worker 2): for-await over uploadChannel — if cancelled/aborted: delete file if exists (existsSync + unlinkSync), continue; caption = formatDumpCaption({from ripResult + trackId}); activeUploadText = `⬆️ <b>Uploading:</b> <i>{trackLabel}</i>` (escaped) where trackLabel = `${ripResult.artist} - ${ripResult.title}`; emitProgress. `dumpMsg = tg.sendMedia(env.DUMP_CHANNEL_ID, {type: 'audio', file: filePath, title, performer, duration}, {caption, progressCallback})` with maxRetries = 4, backoff `uploadRetryBaseMs * 2^(attempt-1) + random*500` via abortableSleep (signal-swallowed); on final failure throw. After success: if `dumpMsg?.media?.type === 'audio'`:
       - saveTrack({appleTrackId: trackId, messageId: dumpMsg.id, fileId: media.fileId, fileUniqueId: media.uniqueFileId, title, artist, album, duration, bitDepth, sampleRate, genre, releaseDate, trackNumber, trackCount})
       - if !isCacheOnly: sendDumpCopy to deliveryChatId (same replyTo/silent rules)
       - clear texts; rippedCountInner++; job.rippedCount; info 'Track completed' or 'Track cached to dump' (isCacheOnly) with time `${(ms/1000).toFixed(1)}s`; logRequest completed
       - failure path: failedTracks.push, failedCount, error 'Track upload failed', logRequest failed + errorReason; if cancelled break
       - else (no audio media): failedTracks.push {id, error: 'Upload failed: no audio media returned'}; error 'Track upload failed: no audio media returned'
       - finally: delete file (unlinkSync if exists), rmSync ripJobDir recursive force (best-effort)
    g. await Promise.all([producer, downloader, uploader]); totalElapsedSec = `((Date.now() - queueStartTime)/1000).toFixed(1)`; jobSummary {jobId, jobHeader, totalTracks, cachedCount, rippedCount: rippedCountInner, failedCount: len(failedTracks), failedTracks, skippedUncachedTracks: [], totalElapsedSec, cappedCount, maxCollectionLimit, isCacheOnly, isGroup}.
19. Outer success: completed = true; emit job:completed; return summary. Catch: completed = true; emit job:failed (err); rethrow. Finally: jobs.delete(id).

Events (EventEmitter): job:created, job:started, job:progress, job:completed, job:cancelled, job:failed.
