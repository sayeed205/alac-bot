## Verified parity facts

### progress.rs (port all four exactly)

- `render_progress_bar(current, total, length=12)`: total<=0 or NaN → `[░×12] 0%`; fraction clamped 0..1; filled = round(fraction*length); percent = round(fraction*100); output `[█×filled░×empty] {percent}%`.
- `format_mb_progress`: `{current_mb:.1}/{total_mb:.1} MB` when total>0 else `{current_mb:.1} MB` (MB = bytes/1048576).
- `format_byte_progress`: `{bar} ({cur}/{total} MB)` when total>0 else `{cur_mb:.1} MB`.
- `format_bytes(bytes)`: <=0 → `0 B`; units B,KB,MB,GB,TB; i = floor(log(bytes)/log(1024)) clamped 0..4; val = bytes/1024^i formatted `{:.0}` for i==0 else `{:.2}`; `{val} {unit}`. (JS toFixed vs Rust {:.N} rounding differ at exact ties — cosmetic, accept.)

### tagger.rs

- `sanitize_filename(name)`: replace `[<>:"/\\|?*]` each with `_`, trim, empty → `"track"`.
- `build_track_filename(meta)`: n = `String(meta.trackNumber || 1)` **JS falsy: 0 → 1** then pad to width 2 (`{:02}`); explicit suffix ` [E]` when meta.explicit; result `"{n}. {title} - {artist}{ [E]} [ALAC].m4a"` with title/artist sanitized via the combined string (sanitize wraps the WHOLE `{n}. {title} - {artist}{explicit} [ALAC]` string, then + `.m4a`).
- `tag_m4a_file(params)`: writes `{output_path}.cover.jpg` when cover non-empty (len > 0); ffmpeg args EXACT order:
  1. `ffmpeg -y -i {raw}`
  2. with cover: `-i {cover} -map 0:a -map 1 -c copy -disposition:v:0 attached_pic`; without: `-c copy`
  3. metadata conditionals (JS falsy — empty/0 skip): `title={title}`, `artist=`, `album=`, `album_artist=` (note: ffmpeg key `album_artist`), `date={releaseDate}`, `genre=`, `composer=`, `track={n}[/{count}]` (track 0 → SKIP; count 0 → omit `/{count}`), `disc={n}[/{count}]` (same), `lyrics={lyrics}` when lyrics non-empty
  4. `{output_path}`
- Exit != 0 → error `FFmpeg tagging failed (exit code {code}): {stderr LAST 200 chars}`. Cover temp removed in all paths (TS finally). Success → returns output_path.

### lyrics.rs

- `LyricsTier { WordSynced=1000, LineSynced=500, Plain=100, None=0 }` (i32 values used in scoring math).
- `WORD_SYNC_REGEX = /<\d{1,3}:\d{2}(?:[.:]\d{2,3})?>/`, `LINE_SYNC_REGEX = /\[\d{1,3}:\d{2}(?:[.:]\d{2,3})?]/`.
- `format_timestamp(time_str)`: contains ':' → `min*60 + sec` from split; else parseFloat; NaN → 0; output `{:02}:{:02}.{:03}` where min=floor(t/60), sec=floor(t%60), ms=floor(round((t%1)*1000)).
- `convert_ttml_to_elrc(ttml)`: if no `<span` or no `begin=` → None. For each `<p ...begin="X"...>(inner)</p>` (case-insensitive): lineStart = format_timestamp(begin or "0"); each `<span ...begin="Y"...>(text)</span>` (case-insensitive): wordStart = format_timestamp(Y), wordText = strip tags, replace `&amp;`→`&`, `&quot;`→`"`, `&#39;`→`'`; append `<{wordStart}>{wordText} `. If wordCount>0 → line `[{lineStart}]<...>... ` trim_end. Else: cleanLine = strip tags + trim; non-empty → `[{lineStart}]{cleanLine}`. Join with `\n`; empty → None. (Rust `regex` crate: build the two regexes with `(?is)` flags; JS `[\s\S]*?` → `(?s).*?`.)
- `detect_lyrics_tier(lyrics)`: trim; empty or len<10 → None-tier; split '\n' filter non-empty-trim lines; <2 lines → None; any line matches WORD → WordSynced; else any matches LINE → LineSynced; else Plain.
- `score_lyrics(text, provider, provider_weight=0) -> LyricsCandidate { text: trimmed, provider, tier, score }`: score = tier + weight when tier != None else 0.
- HTTP seam: `pub trait LyricsHttp: Send + Sync { fn get_json(&self, url: &str) -> impl Future<Output = Option<String>> + Send }` — production: reqwest, UA `AlacBot/1.0`, 5s timeout, !ok → None, network/timeout → None, body text on success. NOTE: TS catches JSON parse errors too → provider returns []. So the provider fns map `Option<String>` (body) → parse → on parse failure → `vec![]`.
- Providers (each: all failures → `vec![]`):
  - **Paxsenix** `https://lyrics.paxsenix.org/apple-music/lyrics?id={urlencode(trackId)}` (encodeURIComponent-style); JSON `{elrc?, ttmlContent?, lrc?, plain?}` (all nullable strings). Candidates (only when trimmed non-empty): elrc → `("Paxsenix Apple Music (ELRC)", 30)`; ttmlContent → convert → `("Paxsenix Apple Music (TTML-ELRC)", 30)` (skip when conversion returns None); lrc → `("Paxsenix Apple Music (LRC)", 25)`; plain → `("Paxsenix Apple Music (Plain)", 20)`.
  - **BetterLyrics** `https://lyrics-api.boidu.dev/getLyrics?s={enc(title)}&a={enc(artist)}`; JSON `{ttml?, lrc?}`; ttml → convert → `("BetterLyrics (Word Synced)", 25)`; lrc → `("BetterLyrics (LRC)", 20)`.
  - **LRCLIB exact** `https://lrclib.net/api/get?` + **form-urlencoded** params `artist_name`, `track_name`, `album_name` (when non-empty string — falsy check), `duration` (when > 0); JSON `{syncedLyrics?, plainLyrics?}`; synced → `("LRCLIB Exact (LRC)", 15)`; plain → `("LRCLIB Exact (Plain)", 10)`.
  - **LRCLIB search** `https://lrclib.net/api/search?` + form-urlencoded `q={title} {artist}` (literal space between → form-encoding makes it `+`); JSON array of `{syncedLyrics?, plainLyrics?, duration?}`; empty/invalid → `[]`; **stable sort** by `|duration - target|` ascending (when target > 0; target 0/None → keep original order); pick first; synced → `("LRCLIB Search (LRC)", 5)`; plain → `("LRCLIB Search (Plain)", 0)`.
  - **form-urlencode** (URLSearchParams parity): space → `+`, unreserved `[A-Za-z0-9-_.~]` kept, everything else `%XX` uppercase hex. (Different from encodeURIComponent: `'` `(` `)` `!` `*` are encoded here.) The catalog `urlencode` (encodeURIComponent parity) stays where TS uses encodeURIComponent (paxsenix id, better-lyrics s/a).
- `fetch_lyrics(track_id, meta {title, artist, album, duration})`: run all 4 providers CONCURRENTLY (join), flatten candidates, filter `tier != None && score > 0`, **stable** sort score desc, return `Some(top.text)` or None.

### ripper.rs

- `RipError`: `Message(String)` (all TS errors are strings) + `#[from] StreamError/CatalogError/io::Error` conversions (to_string).
- `pub type RipProgressCallback = Arc<dyn Fn(&str, Option<u64>, Option<u64>) + Send + Sync>` — (status, downloaded_bytes, total_bytes). Most call sites pass (status, None, None).
- `RipperConfig`/constructor params: `default_output_dir` (String), `max_retries` (default 3), `base_delay_ms` (default 2000).
- `RipperDeps` trait (RPITIT, static dispatch — impl by production bundle AND test fakes):
  ```rust
  pub trait RipperDeps: Send + Sync {
      fn track_meta(&self, track_id: &str, storefront: &str) -> impl Future<Output = Result<TrackMeta, RipError>> + Send;
      // None = mirror lookup failed (TS catches → null → wrapper fallback path)
      fn mirror_endpoint(&self, signal: Option<&CancellationToken>) -> impl Future<Output = Option<MirrorEndpoint>> + Send;
      fn connect_stream(&self, track_id: &str, primary: Option<MirrorEndpoint>, signal: Option<CancellationToken>, on_progress: Option<streaming::ProgressCallback>) -> impl Future<Output = Result<AudioStreamSource, RipError>> + Send;
      fn fetch_lyrics(&self, track_id: &str, meta: &LyricsMeta) -> impl Future<Output = Option<String>> + Send;

      fn tag_m4a(&self, raw_path: &Path, output_path: &Path, meta: &TrackMeta, cover: Option<&[u8]>, lyrics: Option<&str>) -> impl Future<Output = Result<(), RipError>> + Send;

  ```
- `AlacTrackRipper<D: RipperDeps>`:
  - `pub async fn rip(&self, deps-or-held, track_id: &str, on_progress: Option<&RipProgressCallback>, storefront: &str, signal: Option<CancellationToken>, output_dir: Option<&str>) -> Result<TrackRipResult, RipError>`
  - **Retry loop** (exact TS semantics): attempt=0; loop { token cancelled → Err('Download was cancelled'); try rip_once; on Err: cancelled OR message == "Download was cancelled" → rethrow immediately; attempt >= max_retries → rethrow; attempt += 1; raw = base * 2^(attempt-1); jitter = 0.8 + rnd*0.4 (xorshift seeded from time nanos; range 0.8..1.2); delay = round(raw*jitter); progress(`⚠️ Rip failed, retrying (attempt {attempt}/{max_retries}) in {delay/1000:.1}s: {msg}`); warn log; abortable sleep (cancel → 'Download was cancelled') }. With max_retries=3 → 4 total attempts, messages `1/3`, `2/3`, `3/3`.
  - **rip_once flow** (exact progress strings):
    1. cancelled check; mkdir recursive target_dir (output_dir override or default); Err('Download was cancelled') if token cancelled
    2. progress('Fetching track metadata...'); meta = deps.track_meta
    3. cancelled check
    4. progress(`Connecting stream for {artist} - {title}...`)
    5. START concurrently: lyrics fetch (map errors → None, debug log) + artwork fetch (meta.artwork_url non-empty → fetch else None)
    6. primary = deps.mirror_endpoint (None on failure + debug log — NOT an error)
    7. stream = deps.connect_stream (progress callback adapted to status-only)
    8. raw temp file `{output_dir}/stream_{track_id}_{unix_ms}.raw`; final = `{output_dir}/{build_track_filename(meta)}`
    9. stream loop: per-chunk **45s inactivity timeout** (fresh timeout per chunk read; on expiry → Err(`Audio stream stalled on {source_name}: no data received for 45s`)); before each read check cancelled → Err('Download was cancelled'); append chunk; downloaded += len; progress throttle: emit `Downloading lossless audio: {format_byte_progress(downloaded, total_or_0)}` + (downloaded, Some(total) when >0) at most once per 1000ms (test with paused tokio time or coarse assertion)
    10. after loop: cancelled check; progress('Tagging and embedding lossless artwork...'); await artwork + lyrics (both already running); cancelled check; deps.tag_m4a
    11. Result mapping (TS exact): file_path, title, artist, album, duration (meta.duration_secs), codec/bit_depth/sample_rate (from stream), genre: `meta.genre || 'Unknown'` (empty → 'Unknown'), release_date: meta.release_date (already `''` default — TS `meta.releaseDate || ''`), track_number: `meta.track_number ?? 1`, track_count: `meta.track_count ?? 1`
    12. ALWAYS remove temp raw file (TS finally unlink .catch ignore)
- Production deps bundle `EngineRipperDeps<MC: MirrorHttp, SC: StreamHttp, LH: LyricsHttp>`: holds `Catalog<ReqwestTransport>`, `MirrorPolicyManager<MC>`, `StreamTransport<SC>`, wrapper url/key (from env config — `wrapper_url` default `http://127.0.0.1:12340`, `wrapper_api_key` Option), `reqwest::Client` for artwork, `LyricsHttp` impl for lyrics. `connect_stream` calls `StreamTransport::connect_audio_stream` with the wrapper options; `tag_m4a` calls `tagger::tag_m4a_file` with the real ffmpeg runner; `fetch_artwork` = reqwest GET UA `AlacBot/1.0` 15s timeout (`.bytes()`), !ok → None.
- The ripper itself holds only config (dir/retries/delay); deps passed to `rip` (or held at construction — pick ONE, document; constructor-held `Arc<dyn>`? NO — RPITIT can't be dyn. Ripper holds `D: RipperDeps` generic at construction: `AlacTrackRipper::new(deps, config)`).
