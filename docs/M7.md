# Milestone 7 — Full ops/admin sweep (parity)

Status: complete. Source oracles: `src/modules/alac/commands/{health,queue,
stats,info,clean,delete,spec,index_cmd,backup,report}.ts`, `src/modules/alac/
{spectrogram.ts,indexer.ts,stats.ts}`, `src/db/dump.ts`, and
`src/modules/alac/repositories/stats.repository.ts` (~1,600 lines combined).
M7 ports the entire remaining ops/admin surface except `/search`, `/random`,
and `/dumpnew`+`/autodump` (scheduled for later milestones).

## Deliverables

### Shared seams (all lanes build on these)

- `crates/bot/src/lib.rs` — `BotState` gains `admin_id`, `dump_channel_id`,
  `dump_peer`, `stats: Option<db::StatsRepository>`, `db_client`, and
  `started_at` (process uptime source for `/health`).
- `crates/bot/src/rip_deps.rs` — public `tracks()` / `catalog()` accessors.
- `crates/db/src/stats.rs` — `StatsRepository::get_stats()`: one round-trip
  aggregate over tracks/requests (counts, hit ratio, failure count, completed
  averages, top-5 by completed requests). Oracle `Math.round(ratio*1000)/10`
  ratio rounding preserved.
- Callback routing: `report:` prefix dispatch in `handlers::register`.

### `/health` + `/ping`, `/queue`, `/stats` (ops.rs)

- Authed gate (silent return). `🏓 Testing system health...` probe reply →
  edit into the full health card: Telegram/DB/mirror latencies (`Operational`/
  `Degraded`, mirror label from the M5c probe), uptime (d/h/m/s compound),
  RSS via `/proc/self/statm` (no new dependency), rip-worker state
  (`Processing (n queued)` / `Idle`) from `get_active_jobs()` phases.
- `/queue`: idle vs active cards with exact task/tasks pluralization.
- `/stats`: admin-gated (restricted card), `formatStatsHtml` parity
  (storage/caching, latency averages via `formatDurationMs`, top tracks with
  Apple Music links and request pluralization, `0ms`/`ms`/`s`/`m s` tiers).

### `/info` (info.rs)

- `parse_alac_input` (with reply-text resolution) → catalog `fetch_track_meta`
  → cache lookup. Metadata block (album, track n of m, m:ss duration, release
  year, genre, Apple Track ID) + cache-status block (`❌ Not Cached` with rip
  hint vs `✅ Cached in Database` with `ALAC • bit • kHz` quality and
  `#messageId`).
- Deviation (accepted): quality fields come from a full-row
  `search_cached_tracks` lookup because `find_cached_tracks` returns the
  orchestration projection without bit depth/sample rate.

### `/clean` (clean.rs)

- Admin-gated. Walks `bot-data/downloads`, skips `.gitkeep`/`.gitignore`,
  counts/sums/removes files, reports with `formatBytes` parity
  (log-scale unit pick, 0 decimals at B, 2 above).

### `/delete` (delete.rs)

- Admin-gated. Parse → cache lookup (`Track Not Found` card) → dump-message
  delete (channel-aware, errors swallowed) → `delete_track` → success card
  (title/artist fallbacks `Track {id}` / `Unknown Artist`, `#messageId`).

### `/spec` + aliases `spectogram`/`spectrogram`/`spek` (spec.rs + spectrogram.rs)

- Authed-or-admin gate. Reply-media classification: audio documents by
  mime/audio attributes (voice → `.ogg` `Voice Note`, audio ext list),
  unsupported media card.
- `ffprobe -print_format json` probe (serde_json; tag key matching is
  case-insensitive across format+stream tags, `bits_per_raw_sample ||
  bits_per_sample`, stream-or-format duration/bitrate fallbacks), probe
  failures fall back to file-derived defaults exactly like the oracle.
- SoX spectrogram with the oracle's exact flags (`-x 1200 -y 551 -z 120`,
  `-d {secs:.2}` when duration known, `-t title`, `-c comment`) and an
  ffmpeg→wav→SoX fallback path (the oracle pipes ffmpeg stdout into SoX
  stdin; the Rust port writes an intermediate WAV — same terminal behavior,
  noted deviation).
- Upload: `upload_file` → `as_photo_media()` → `InputMessage::copy_media`
  sent replying to the analyzed message; status message deleted in a
  `finally`-style cleanup; failure edits the status with the escaped error.

### `/index` (index.rs)

- Admin-gated, `AtomicBool` re-entry guard (`Dump channel sync is already in
  progress.`). Probe message → max id → backward batches of 100 via
  `get_messages` (missing ids = deleted messages, skipped).
- Audio classification (audio attribute, not voice), `parse_dump_caption`
  payload extraction, `file_ids` matching the sink's mtproto format,
  `save_track` with title/artist fallbacks, `delete_tracks_not_in` prune.
- Progress edits throttled to ≥2s (`Scanned`/`Synced` counts), summary card
  with `Time Elapsed: {sec:.1}s`.

### `/export` + `/import` (backup.rs + db/dump.rs)

- Both admin-only AND DM-only (silent return outside private chats — oracle
  parity).
- Export: `DbDumpService::export_dump()` — header comments, per-row
  transactional upsert `INSERT ... ON CONFLICT` statements for
  users/tracks/requests (LEAST/GREATEST merge semantics), serial-sequence
  reset statements, gzip via flate2, `alac_dump_{timestamp}.sql.gz` filename
  (oracle char-mapping), status message → document upload
  (`as_document_media`) → status deleted in a finally-cleanup.
- Import: replied `.sql.gz` document download → gunzip → line-filter
  (`--` comments) → merged-count classification → every statement executed
  in ONE welds transaction, rollback on any failure (`Transaction rolled
  back. Database state remains unchanged.` footer on the error card).
- New workspace dep: `flate2` (db crate).

### `/report` + `/issue` (report.rs)

- In-memory `OnceLock<Mutex<ReportState>>` registries (reports,
  reports-by-track, per-user timestamps) — oracle parity (process-lifetime
  state, not persisted).
- Target resolution order (oracle): replied media `file_unique_id` →
  `find_track_by_file_unique_id`; reply text track-id parse; raw-args first
  token (custom reason = remainder); `find_cached_tracks` map lookup.
- Sliding-window rate limit: 5 reports/hour/user, admin exempt, pure
  `check_user_rate_limit(state, user, now_ms)` helper (tested).
- `extract_track_id_from_text`: regex crate port of the oracle song-URL
  (`?i=` group preferred) and 8-11 digit patterns (tested).
- Preset picker keyboard (corrupted/incomplete/metadata/other/cancel),
  `other` → custom-note editor with close button.
- `dispatch_report`: 8-char id, admin card (reporter link, track block, dump
  `t.me/c/` link with marked-id cleanup, blockquote reason) + admin action
  keyboard (Re-rip Now (-f) / Delete Track / Dismiss), reporter confirmation
  cards, courtesy notices on admin actions.
- Rerip: `RipJobOptions { is_force: true, is_cache_only: true, ... }` through
  `rip_orchestrator.start_job` — with a fresh `🔍 Resolving...` status
  message sent to the rip chat first (oracle `executeRipPipeline` without
  `msg`/`statusMessageToReuse` semantics: the pipeline edits its own
  message, never the admin card). Cache-only force mode re-rips and replaces
  the corrupted dump (M5c engine path), old message deleted, report closed.
- Delete: dump-message delete + `delete_track` + reporter courtesy + closed
  card. Dismiss: registry removal + dismissed card.
- New bot-crate dep: `regex` (already in workspace).

## Intentional deviations (recorded)

- `/spec` ffmpeg fallback writes an intermediate WAV instead of piping
  ffmpeg stdout → SoX stdin (same command semantics, one extra temp file).
- `/info` quality fields use a full-row `search_cached_tracks` lookup
  (projection lacks bit depth/sample rate).
- `format_duration_ms` uses integer half-up tenths rounding (JS `toFixed`
  float quirks only differ at exact `.x5` boundaries).
- `/index` progress edits are spawned as detached edits (oracle awaits
  them); the final summary edit is awaited.
